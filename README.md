**보기:** https://geben147-create.github.io/gongtong-sheet/

## 주의
- 팔로워·게시물·좋아요·댓글: ego 비로그인 공개값 (수집 시각 표기, K 단위 반올림 포함). 좋아요 숨김 게시물은 "숨김".
- 공통기억 속 매출·조회수 등 과거 GPT 대화 수치는 **검증 안 됨**.
- 번역·"최근 게시물 분석" 요약은 로컬 Qwen3.6-27B 자동 생성.
- 썸네일 저작권은 각 계정에 있음 — 벤치마킹 참고용 축소본, 클릭 시 원본으로 이동.
- 강의 슬라이드 등 VIEW/media 캡처 이미지는 공개 저장소에 넣지 않음.

## 갱신
1. `tools/tmpl.js`의 `__H__`(계정 배열)·`__M__`(게시물 수)를 채워 `ego < batch.js > out_x.txt` 로 수집 (계정당 ~16초)
2. `python3 -I tools/build.py` (로컬 Qwen 8081 사용, `--noai`면 번역·요약 생략)
